# Generated reference angle assets

Status: `GENERATED_REFERENCE_ACTIVE`

OptiHome now includes generated reference views for the current eight catalogue frames so the virtual try-on can show apparent temple/arm depth while the user turns their head.

## Scope

- The existing frontal WebP remains the reference front view.
- Three-quarter and side views are generated vector references derived from each frame's catalogue style, material/color family and silhouette class.
- Left-facing views are mirrored from the generated right-facing reference when an authentic left view is unavailable.
- These generated views are intended for visual style/proportion guidance only.

## Provenance

`Frame.tryOnAnglesAuthority = GENERATED_REFERENCE`

The frame catalogue itself remains `authority: REFERENCE`.

## Authentic asset gate

`EXTERNAL_ASSET_GATE_OPEN` remains open for product-authentic photography/renders. Generated reference views must be replaced when normalized authentic `front`, `left-3q`, `right-3q`, `left-side`, and `right-side` views become available.

Generated references must never be represented as measured product geometry.
