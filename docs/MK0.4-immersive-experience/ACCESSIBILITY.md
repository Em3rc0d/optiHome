# ACCESSIBILITY

## Contract

- Keyboard-only navigation preserved.
- Focus-visible remains global and high contrast.
- Semantic heading/order preserved.
- Carousel surfaces expose labels and keyboard arrow navigation.
- Filter state uses `aria-pressed`.
- Catalog count uses `aria-live`.
- Decorative motion has no semantic dependency.
- `prefers-reduced-motion` is honored globally and inside Framer Motion.
- No content is hidden behind animation.
- No hover-only information.
